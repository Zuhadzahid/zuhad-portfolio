# zuhad-portfolio

Personal portfolio of **Zuhad Zahid** — Software Engineer building for an AI-first world.

- Full-stack & DevOps Engineer
- Founder | Builder
- Karachi, Sindh, Pakistan

## Tech Stack

- [Next.js 16](https://nextjs.org)
- [React 19](https://react.dev)
- [Tailwind CSS v4](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com)
- [Motion](https://motion.dev)

## Features

- Custom isometric **ZZ** brand mark with cursor spotlight and press interaction
- Light & dark theme support
- Interactive avatar with lights toggle
- Name pronunciation audio
- Blog with MDX & Markdown support
- SEO optimization: JSON-LD schema, sitemap, robots
- Installable PWA

## Development

```bash
pnpm install
pnpm dev
```

The app runs at http://localhost:3000

To build for production:

```bash
pnpm build
```
